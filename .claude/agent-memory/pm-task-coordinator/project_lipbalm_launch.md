저자극 비건 립밤 신상품 출시 기획 프로젝트 (2026-06-28 회의록 기반).

**Why:** 20~30대 여성 타깃, "민감한 입술도 편안하게 사용할 수 있는 데일리 보습 립밤" 콘셉트. 시장 검증 → 경쟁 분석 → 마케팅 실행 → 경영진 보고 순서의 신규 출시 프로젝트.

**Key constraints:**
- 초기 마케팅 예산: 300만 원 이내
- 마케팅 채널: 인스타그램, 유튜브 쇼츠, 인플루언서 협찬, 체험단, 숏폼 콘텐츠
- 출시 일정표 필요 (패키지 디자인 → 샘플 제작 → 상세페이지 → 촬영 → 마케팅 오픈)
- 경영진 보고서 + 내부 발표자료(8장) 필요

**TASK breakdown (2026-06-28):**
- TASK-001: 시장 트렌드 조사 → notion-research-agent
- TASK-002: 경쟁 제품 분석 → notion-research-agent
- TASK-003: 뷰티 인플루언서 후보 리스트 → notion-research-agent
- TASK-004: 마케팅 실행안 작성 → notion-work-agent
- TASK-005: 제품 이미지 비주얼 콘셉트 기획 → notion-visual-agent
- TASK-006: 제품 출시 개발 일정표 → notion-schedule-agent
- TASK-007: 외주 문의 이메일 초안 → notion-work-agent
- TASK-008: 경영진 보고서 작성 → notion-work-agent
- TASK-009: 내부 발표자료 개요(8장) → notion-visual-agent
