## 기계 학습 (머신 러닝, Machine Learning)

### 개요

기계 학습(機械學習) 또는 머신 러닝(영어: machine learning, ML)은 경험을 통해 자동으로 개선하는 컴퓨터 알고리즘의 연구이다. 방대한 데이터를 분석해 '미래를 예측하는 기술'이자 인공지능의 한 분야로 간주된다. 기계 학습은 복잡한 패턴에 대한 학습을 통해 상황에 대한 예측과 의사 결정을 돕는다. 컴퓨터가 학습할 수 있도록 하는 알고리즘과 기술을 개발하는 분야이다.

기계 학습의 핵심은 **표현(representation)**과 **일반화(generalization)**에 있다. 표현이란 데이터의 평가이며, 일반화란 아직 알 수 없는 데이터에 대한 처리이다. 문자 인식은 기계 학습을 이용한 가장 잘 알려진 사례이다.

---

### 정의

1959년, 아서 사무엘(Arthur Samuel)은 기계 학습을 다음과 같이 정의하였다:

> "기계가 일일이 코드로 명시하지 않은 동작을 데이터로부터 학습하여 실행할 수 있도록 하는 알고리즘을 개발하는 연구 분야"

---

### 일반화

기계 학습에서의 일반화는 훈련 이후 새롭게 들어온 데이터를 정확히 처리할 수 있는 능력을 말한다.

---

### 기계 학습 vs 데이터 마이닝

기계 학습과 데이터 마이닝은 종종 같은 방법을 사용하며 상당히 중첩된다. 대략적 구분:

- **기계 학습**: 훈련 데이터를 통해 학습된 알려진 속성을 기반으로 예측에 초점
- **데이터 마이닝**: 데이터의 미처 몰랐던 속성을 발견하는 것에 집중 (데이터베이스 지식 발견 분석 절차)

---

### 알고리즘 유형

1. **지도 학습 (Supervised Learning)** - 레이블된 훈련 데이터로 학습
2. **자율 학습 (Unsupervised Learning)** - 레이블 없이 패턴 발견
3. **준 지도 학습 (Semi-supervised Learning)** - 소량의 레이블 데이터 + 대량의 비레이블 데이터
4. **강화 학습 (Reinforcement Learning)** - 보상을 통해 행동 최적화
5. **심화 학습 / 딥 러닝 (Deep Learning)** - 다층 신경망 기반 학습

| 분류 | 알고리즘 |

### 인공신경망 상세

인공신경망(ANN)은 기계학습과 인지과학에서 생물학의 신경망에서 영감을 얻은 통계학적 학습 알고리즘으로, 시냅스의 결합으로 네트워크를 형성한 인공 뉴런(노드)이 학습을 통해 시냅스의 결합 세기를 변화시켜 문제 해결 능력을 가지는 모델 전반을 가리킨다.

- **교사 학습**: 교사 신호(정답)의 입력에 의해 문제에 최적화 - 명확한 해답이 있는 경우
- **비교사 학습**: 교사 신호를 필요로 하지 않음 - 데이터 클러스터링에 사용

신경망은 규칙기반 프로그래밍으로 풀기 어려운 컴퓨터 비전, 음성 인식 등의 문제를 푸는 데 이용된다.
